ZenTerm terminal embeds NotoSansMonoCJKjp-Regular.otf so Android WebView does
not fall back to a device-specific monospace font for Japanese terminal text.

Source:
https://github.com/notofonts/noto-cjk/releases/download/Sans2.004/11_NotoSansMonoCJKjp.zip

Only the Regular face is bundled to keep the gateway package size smaller. The
font is distributed under the SIL Open Font License 1.1; see OFL.txt.
